# The Patto Dinner Club

Thesis: a cheerful family cookbook that turns “what's for dinner?” into five good nights and one easy shop.

- Identity: a bold neighbourhood dinner-club masthead; illustrated plates are the stars, with tiny kitchen jobs for the kids.
- Palette: oat #fff9ed (canvas), tomato #b83224 (identity/actions), ink #27271f (text), butter #f5d56b (highlights), leaf #345b3e (produce/success), cobalt #304c9b (secondary accents).
- Typography: heavy Georgia display headlines with tight spacing; system sans-serif for clear, large controls and cooking instructions. No external font dependency.
- Layout: desktop `masthead / navigation / headline + dinner illustration / weekly controls / 3 + 2 meal grid`; mobile `masthead / scrollable navigation / headline / controls / single-column meals`. Grocery list uses aisle sections and large checkboxes. Recipes open in a keyboard-accessible dialog.
- Interaction: explicit navigation, a shopping progress meter, checkbox feedback, persistent favourites, portion scaling and a Friday protein switch. Motion is subtle and respects reduced-motion preferences.
- Voice: “Good food. Full table.”, “Let's get cooking”, “One shop. Five happy dinners.”, “Nothing in the scrapbook yet.”
- Principles: food first; helpful family detail; honest provenance; readable at the supermarket; no login or external services.

Direction critique: avoid a generic meal-tracker dashboard. Use an editorial headline, unevenly coloured meal artwork, day-of-week labels, and family kitchen language. No invented family portraits or historic plans. Removed a proposed decorative sticker cluster to keep the meal choices prominent.

Delivery scope: the user explicitly requested end-to-end creation ready for GitHub Pages, so implementation proceeds without a separate design gate. No Sites hosting registration: the requested deployment target is GitHub Pages.
